# CodeFlow 用户试验任务书（自由探索用户） / CodeFlow User Test Task Sheet (Free Exploration Users)

## 中文版

感谢你参与本次测试。

本次测试主要关注：当用户没有被明确指导操作步骤时，是否能够自然地理解并探索该工具的功能。

请在操作过程中尽量说出你在想什么。  
例如：
- “我想先看看这个工具能做什么”
- “我猜这里可以运行”
- “我不确定保存和导出有什么区别”

请根据你自己的理解，自由使用这个工具。  
你的目标是：

### 目标
尝试理解一段代码中变量是如何变化的，并把你觉得有用的结果保存下来。

你可以：
- 打开 example
- 新建项目
- 修改代码
- 查看 step
- 调整显示方式
- 保存项目

没有固定顺序，请按照你自己的方式完成。

### 继续探索（可选）
如果还有时间，请继续尝试更多功能，或进一步完成一个你认为有意义的目标。  
请继续说出你在想什么，以及你接下来最想做什么。

完成后，请回答几个简短问题：

1. 你觉得哪一步最困惑？
2. 你觉得哪一步最顺手？
3. 如果只能改一个地方，你最希望改哪里？

可选补充问题：

4. 你一开始觉得这个工具是做什么的？
5. 你下次还会愿意使用它吗？
6. 有没有哪个按钮、词语或功能让你一开始理解错了？

## English Version

Thank you for taking part in this test.

This session focuses on whether users can naturally understand and explore the tool when they are not given explicit step-by-step instructions.

Please try to say out loud what you are thinking while using the system.  
For example:
- “I want to first see what this tool can do.”
- “I guess I can run it from here.”
- “I'm not sure what the difference is between save and export.”

Please use the tool freely based on your own understanding.  
Your goal is:

### Goal
Try to understand how variables change in a piece of code, and save any result that you find useful.

You may:
- open an example
- create a new project
- modify code
- inspect steps
- change display settings
- save the project

There is no fixed order. Please do it in your own way.

### Continue Exploring (Optional)
If time allows, please continue trying more features, or further complete one goal that you find meaningful.  
Please continue to say out loud what you are thinking and what you want to do next.

After the tasks are completed, please answer a few short questions:

1. Which step felt the most confusing?
2. Which step felt the easiest or most natural?
3. If you could change only one thing, what would you change?

Optional follow-up questions:

4. What did you think this tool was for at first?
5. Would you be willing to use it again?
6. Was there any button, label, or feature that you misunderstood at first?
