# CodeFlow 用户试验任务书（非技术背景用户） / CodeFlow User Test Task Sheet (Non-Technical Users)

## 中文版

感谢你参与本次测试。

本次测试主要关注：不具备较强技术背景的用户，是否能够理解该工具的基本功能，并完成简单操作。

请在操作过程中尽量说出你在想什么。  
例如：
- “我不知道这个按钮是干什么的”
- “我现在想看看这个图是什么意思”
- “我不确定下一步该做什么”

请完成以下任务：

### 任务 1
打开一个 example，并观察界面中显示的结果。

### 任务 2
在界面中选择一个你想查看的内容，并观察它在不同 step 中是如何变化的。

### 任务 3
尝试修改一次显示方式，或者点击一次相关设置，看看结果有什么变化。

### 任务 4
保存当前项目，并尝试重新打开它。

### 自由探索（可选）
如果还有时间，请你自由探索这个工具，并尝试做一件你认为有意义的事情。  
你可以继续查看不同 step、点击界面中的内容、调整显示方式，或尝试理解更多信息。  
请继续说出你在想什么，以及你接下来最想做什么。

完成后，请回答几个简短问题：

1. 你觉得哪一步最困惑？
2. 你觉得哪一步最顺手？
3. 如果只能改一个地方，你最希望改哪里？

可选补充问题：

4. 你一开始觉得这个工具是做什么的？
5. 你下次还会愿意使用它吗？
6. 有没有哪个按钮、词语或功能让你一开始理解错了？

## English Version

Thank you for taking part in this test.

This session focuses on whether users without a strong technical background can understand the basic functions of the tool and complete simple tasks.

Please try to say out loud what you are thinking while using the system.  
For example:
- “I'm not sure what this button does.”
- “I want to understand what this picture means.”
- “I'm not sure what to do next.”

Please complete the following tasks:

### Task 1
Open an example and observe the result shown on the interface.

### Task 2
Choose one item shown in the interface and observe how it changes across different steps.

### Task 3
Try changing one display style, or open one related setting, and see what changes.

### Task 4
Save the current project and try reopening it.

### Free Exploration (Optional)
If time allows, please explore the tool freely and try to do one thing that you find meaningful.  
You may continue viewing different steps, clicking items in the interface, changing display settings, or trying to understand more information.  
Please continue to say out loud what you are thinking and what you want to do next.

After the tasks are completed, please answer a few short questions:

1. Which step felt the most confusing?
2. Which step felt the easiest or most natural?
3. If you could change only one thing, what would you change?

Optional follow-up questions:

4. What did you think this tool was for at first?
5. Would you be willing to use it again?
6. Was there any button, label, or feature that you misunderstood at first?
